# Workstream A — EPIC-021 Deliberate-Regression Test

The roadmap criterion (verbatim): *"A deliberate regression (e.g. setting `transfer_id=NULL` on a paired row, or breaking the rate resolver) causes at least one integration test to fail with a clear message."*

We codify this as a positive detection test: the test mutates a paired transfer to break the invariant, then asserts that the invariant-check view (`v_unreconciled_transfers`) flags it with a clear, structured row. This proves the integration suite would catch the regression in the wild and stays green forever after.

```python
import pytest


@pytest.mark.integration
def test_deliberate_regression_orphan_leg_is_flagged(populated_pipeline_db):
    """EPIC-021 criterion: a deliberate regression must be caught by the suite.

    Mutates a paired transfer leg's transfer_id to NULL and asserts that
    v_unreconciled_transfers surfaces the orphan with enough context for a
    human to debug. This is a positive detection test: it proves the
    integration layer's invariant check works and gives us a regression
    canary for the canary itself.
    """
    conn = populated_pipeline_db

    pair = conn.execute(
        "SELECT id, transfer_id FROM transactions "
        "WHERE transfer_id IS NOT NULL ORDER BY id LIMIT 2"
    ).fetchall()
    assert len(pair) == 2, "fixture must contain at least one paired transfer"
    leg_id, transfer_id = pair[0]["id"], pair[0]["transfer_id"]

    conn.execute(
        "UPDATE transactions SET transfer_id = NULL WHERE id = ?", (leg_id,)
    )
    conn.commit()

    orphans = conn.execute(
        "SELECT * FROM v_unreconciled_transfers WHERE transfer_id = ?",
        (transfer_id,),
    ).fetchall()

    assert orphans, (
        f"v_unreconciled_transfers failed to flag orphan after deleting "
        f"transfer_id from transaction {leg_id}; this means the suite "
        f"would silently miss a real-world transfer break"
    )
    assert len(orphans) == 1, (
        f"expected exactly 1 orphan leg for transfer {transfer_id}; got "
        f"{len(orphans)}: {[dict(r) for r in orphans]}"
    )
```

If the existing fixture is named differently than `populated_pipeline_db`, substitute the actual fixture name from Step 1.
